# Портфолио UX/UI-дизайнера

Первый экран портфолио. При прокрутке обложки выходят из стопки по очереди.

Открой `index.html` в браузере, чтобы посмотреть страницу локально. Для GitHub Pages выбери ветку `main` и папку `/ (root)` в **Settings → Pages**.

## Как заменить обложки

Картинки лежат в `assets/`. Порядок показа — «Дизайн система», «Telegram mini app», «Лендинг и сервис по подбору участка», «Лендинг и онлайн сметы на строительство». Чтобы заменить картинку, сохрани её под тем же именем или обнови `src` у нужной карточки в `index.html`. Подпись задаётся в `data-title`. Если меняешь название первой карточки, обнови и начальную подпись под обложкой.

Чтобы активировать кнопку «Смотреть проект», добавь к нужной обложке в `index.html` атрибут `data-project-url` с адресом проекта.

За размеры, позиции и скорость движения отвечают `styles.css` и `scroll.js`.

Меню в шапке раскрывает подпись выбранного пункта и перемещает подсветку с анимацией по мотивам [Bottom Bar](https://designbookmark.com/motion#db-bottom-bar). Пружины меню настроены в `header-menu.js`.
