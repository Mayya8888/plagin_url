# Портфолио UX/UI-дизайнера

Первый экран портфолио. При прокрутке обложки выходят из стопки по очереди. Кнопка «Смотреть проект» открывает текущую обложку крупнее.

Открой `index.html` в браузере, чтобы посмотреть страницу локально. Для GitHub Pages выбери ветку `main` и папку `/ (root)` в **Settings → Pages**.

## Как заменить обложки

Картинки лежат в `assets/`. Порядок показа — дизайн-система, Good Wood, подбор земельного участка, индекс цен. Чтобы заменить картинку, сохрани её под тем же именем или обнови `src` у нужной карточки в `index.html`. Подпись задаётся в `data-title`. Первая карточка также указана в начальной подписи и ссылке на превью.

За размеры, позиции и скорость движения отвечают `styles.css` и `scroll.js`.
